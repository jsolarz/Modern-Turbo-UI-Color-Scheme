Reading the previews: VS Code colors are taken from each theme’s TextMate palette. Vim uses syntax highlight groups rather than the same token scopes, so the Vim previews are representative mappings—not a guarantee that every Pascal syntax plugin will assign each token identically. Borland Turbo C intentionally targets C/C++ and disables semantic highlighting to preserve its classic token colors. turbo.vim also defines a darker GUI background than the Borland-blue borlandp.vim default.
